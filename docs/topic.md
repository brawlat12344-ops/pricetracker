# Фиксация индивидуальной темы

## Утверждённая тема

**PriceTracker** — сервис, который по одной ссылке на товар в интернет-магазине находит
**ту же или лучшую конфигурацию дешевле**. Результат — разовый отчёт с вердиктом, скидкой,
таблицей характеристик и кликабельными ссылками в магазины. Отслеживаемых товаров,
фонового опроса и поиска аналогов в приложении больше нет.

## Почему тема отличается от типовых работ

| Типовая работа | PriceTracker |
|---|---|
| Сравнение цен вручную | `CheapSearchService`: одна ссылка → адаптеры магазинов → до 10 предложений |
| Любая дешёвая карточка считается подходящей | `SameConfigMatcher`: только не худшая комплектация и строго меньшая цена |
| Характеристики исходника подменяются найденной карточкой | Исходник читается отдельно; подмены нет |
| Сайты блокируют ботов | Честный `warnings` + демо-карточки с бейджем `ДЕМО-ЦЕНА` и ссылкой на реальный поиск |
| Сравнение «просто дешевле» | `CategoryCatalog` + `ComparisonService.evaluate`: «баллы за 1000 ₽» |
| Характеристики ПК «одной строкой» | Матрица из 8 параметров: CPU, GPU, RAM, SSD, БП, охлаждение, ОС, корпус; у каждого вес, иконка и шкала баллов |
| Характеристики только вручную | `SpecProvider`: JSON-LD, meta-теги и эвристики, `mock`/`html` |
| График на JavaScript | Слои, кнопки и списки анимируются чистым CSS, без Node.js |
| Смешанный стек | Полный Java-стек: Spring Boot 3.3, Thymeleaf, Flyway, JDBC, PostgreSQL |
| Схема только на словах | Три уровня C4 в `docs/c4.md` |

## Как подтвердить уникальность в группе

1. Открой список закреплённых тем группы.
2. Найди строки с ключевыми словами: «цены», «магазин», «скидки», «комплектация».
3. Сравни не название, а поведение: строгая проверка конфигурации, демо-фолбэк с предупреждением, C4-схемы.
4. Если у другого участника похожая тема, отличия фиксируются таблицей выше.

Итог: тема зафиксирована как «поиск той же или лучшей комплектации дешевле по одной ссылке
с честным демо-фолбэком и 10-балльной оценкой конфигурации и цены».

## Минимальный пользовательский сценарий

1. Открыть `http://localhost`, войти под `demo@example.com` / `demopass123` (регистрации нет).
2. На странице «Найти дешевле» вставить ссылку, например с `dns-shop.ru`.
3. Выбрать тему «Сборка ПК» и до 10 предложений, оставить «Искать во всех магазинах».
4. Нажать «Найти дешевле» и посмотреть вердикт, скидки и таблицу comparison.
5. Перейти по названию предложения в магазин и проверить актуальную цену вручную.
