# Фиксация индивидуальной темы

## Утверждённая тема

**PriceTracker** — система мониторинга цен и сравнения товаров по темам (ноутбуки, телефоны, наушники, сборки ПК)
с фоновым парсером, историей снимков, дневной агрегацией и алертами. Сравнение отвечает на вопрос
«что лучше за указанную цену»: баллы за комплектацию делятся на актуальную цену из карточки.

## Почему тема отличается от типовых работ

| Типовая работа | PriceTracker |
|---|---|
| CRUD-приложение без фона | отдельный процесс `worker` с `@Scheduled` опросом |
| Цена хранится одной строкой | история снимков + уникальный ключ на интервал |
| Повторный запрос создаёт дубли | `INSERT ... ON CONFLICT DO NOTHING` |
| График на JavaScript | SVG генерируется сервером, Node.js отсутствует |
| Смешанный стек | полный Java-стек: Spring Boot, Thymeleaf, Flyway, JDBC |
| Сравнение цен вручную | `CategoryCatalog` + `ComparisonService`: веса характеристик и «баллы за 1000 ₽» |
| Характеристики только вручную | `SpecProvider`: JSON-LD, meta-теги и эвристики из URL товара |
| Схема только на словах | три уровня C4 в `docs/c4.md` |

## Как подтвердить уникальность в группе

1. Открой список закреплённых тем группы.
2. Найди строки с ключевыми словами: «цены», «парсер», «мониторинг», «магазин», «скидки».
3. Сравни не только название, а реализацию: отдельный воркер, идемпотентные снимки, C4-схемы, Java-стек.
4. Если у другого участника похожая тема, отличия фиксируются таблицей выше.

Итог: тема зафиксирована как «мониторинг цен и сравнение комплектаций за цену с фоновым опросом и историей снимков»; указанные признаки отличают работу от простого CRUD-приложения.

## Минимальный пользовательский сценарий

1. Открыть `http://localhost`.
2. Зарегистрироваться: `test@mail.ru` / `qwerty123`.
3. Добавить товар: URL `https://shop.example/product/42`, название «Кроссовки», порог `9500`.
4. Нажать «Опросить» → получить цену и алерт.
5. Открыть график товара.
6. Повторно нажать «Опросить» в ту же минуту → дубль не создаётся.
7. Добавить второй ноутбук, отметить оба чекбоксами → «Сравнить выбранные (2–4)».
8. На странице `/compare` посмотреть таблицу характеристик, баллы и вердикт «Лучшее за цену».
